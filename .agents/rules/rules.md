# ПРАВИЛА ПРОЕКТА INFINITY-VERSE ДЛЯ АГЕНТОВ (AGENTS.md)

0. **Обращение и коммуникация:**
   - Пользователя зовут: **Ник**
   - Ассистента зовут: **Джими**
   - Общаемся на **«ты»**, прямо и по делу.

1. **Контекст и приватные заметки:**
   Обязательно читай файлы в .private/ (выжимка предыдущего чата.md, скелет проекта.md).

2. **Окружение:**
   Проект работает в чистом Windows (PowerShell, Node.js, Git).

3. **Синхронизация и пуш:**
   - Обновлять `.private/выжимка предыдущего чата.md`.
   - Запускать пуш через `scripts/push_all.ps1` (скрипт настроен на мгновенный неблокирующий пуш по токену из `.private/wallets.env` с отключенными интерактивными промптами Git). Никаких зависаний.

4. **Компиляция и деплой смарт-контрактов:**
   - Для всех смарт-контрактов (Main, AAA, TTT, BBB и др.) оптимизатор Solidity компилятора (`optimizer`) **всегда** включается с абсолютным максимумом: `runs: 4294967295` (2^32 - 1). Никаких `runs: 200` по умолчанию. Это минимизирует стоимость газа в рантайме Monad EVM.
   - Если размер контракта приближается к лимиту EVM (24 576 байт), логика выносится в модули-сателлиты (например, будущий контракт BBB), а не ухудшается оптимизатор.
