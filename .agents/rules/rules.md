# ПРАВИЛА ПРОЕКТА INFINITY-VERSE

1. **Обязательное чтение контекста:**
   Всегда читай файлы из //wsl.localhost/Ubuntu/home/dikanevn/infinity-verse/.private (в частности: выжимка предыдущего чата.md, скелет проекта.md).

2. **Работа с файлами и среда WSL:**
   Проект находится внутри Linux WSL (/home/dikanevn/infinity-verse).
   - НЕ использовать Windows PowerShell или CMD для редактирования и патчинга исходного кода проекта (во избежание проблем с кодировками utf-8 и кавычками).
   - Все изменения кода, компиляцию, тесты и запуск скриптов выполнять напрямую внутри среды WSL: wsl -d Ubuntu -- ...
   - Изменения в коде вносить точечно и чисто через Linux-утилиты или прямое чтение/запись в Linux.

3. **Синхронизация и выжимка:**
   При каждом ответе обновлять выжимка предыдущего чата.md и вызывать push_all.sh для синхронизации обоих репозиториев (основного и .private).
