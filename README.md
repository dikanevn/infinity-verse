# Infinity Verse

An Autonomous World (AW) / Fully On-chain Game (FOCG) designed for longevity and modular upgradeability.

## Core Concepts

- **VerseState (Storage):** Minimal persistent state machine keeping registry of epochs and ownership.
- **VerseLogic (Rules Engine):** Decoupled execution logic handling game movement, NPC actions, and state transitions.
- **Epoch Transition (Handshake):** Upgrade protocol linking generations (V1 -> V2) with immutable seals (0x...dEaD).
